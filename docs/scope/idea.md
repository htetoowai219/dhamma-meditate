# Idea: Quick Meditate

**Date:** 2026-11-28

## One-Liner
A one-off "Quick Meditate" flow on the home page of DhammaMeditate that lets users configure and start a meditation session immediately without saving it as a template.

## Problem / Purpose
Currently, starting a meditation requires creating and saving a named session template first. Users who just want to sit right away with a chosen intro, main audio, and timer shouldn't have to save a reusable session just to meditate once.

## Core Must-Haves
- Add a **Quick Meditate** button on the home page.
- Tapping **Quick Meditate** opens a setup page similar to the Create New Session page (without requiring a saved template).
- Let the user select the intro audio, the main audio, and the timer on that page.
- Provide a **Start** button that immediately starts the meditation session without saving it to the user's sessions list.
